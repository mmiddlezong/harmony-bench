# HarmonyBench

How well can AI models read harmony from sheet music?

The first test is the simplest one: a single major or minor chord in root position, written
for four voices (soprano, alto, tenor, bass) on a grand staff. The model has to name it.

## How the test works

Every chord is generated by a program and checked twice: the voicing follows textbook
four-part writing rules (root in the bass, root doubled, no crossed voices, standard
ranges), and each finished file is read back and re-analyzed before it is kept. The
first set has 60 chords: the 15 major and 15 minor triads named after the standard keys,
each written once with accidentals on the notes and once under a key signature where the
chord is not the tonic, so the key signature doesn't give the answer away.

Each model sees each chord twice:

- **as an image** of the score, and
- **as MusicXML text**, with no image.

Comparing the two separates misreading the score from not knowing the harmony.

Models answer in their own words. A cheap judge model (GPT-6 Luna) reads each answer,
works out which chord the model finally committed to, and compares it with the answer key.
An answer counts as correct only if the root is spelled as written (G♭ is not F♯) and the
quality is right. A rule-based parser double-checks every judgment and flags any
disagreement for a person to look at.

The chords themselves are not published, so they can't end up in training data. The code
that generates them is public, but the random seed that picks the real test set is not.

## Run it yourself

You need [uv](https://docs.astral.sh/uv/) and API keys for the models you want to test.

```bash
uv sync
cp .env.example .env                     # then add your API keys
uv run harmonybench build --seed 1       # generate a set of chords (data/triads_root/)
uv run harmonybench estimate anthropic   # see what a run will cost before paying for it
uv run harmonybench run anthropic        # ask the models, then judge their answers
uv run harmonybench score                # updates the results table above
```

Other commands: `harmonybench models` lists the configured models; `errors <model>` shows
the chords a model got wrong; `disagreements` shows judgments the parser flagged;
`compare <a> <b>` tests whether two models really differ; `prompt` prints the exact
prompts. Open `data/triads_root/review.html` to check every chord against its label by eye.

To add a model, add an entry to `configs/models.yaml` and run
`uv run harmonybench run <model-id>`.

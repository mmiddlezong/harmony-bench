Can AI find the wrong note?

I took 15 excerpts from various musical arrangements and compositions, modified one note, and asked frontier AI models which measure the changed note is in.

Try one

This is a sample and not included in the benchmark. Here's the prompt:

This is an image of part of a score. One note has been modified from the original. Which measure is it in? Answer with its bar number.

Methodology

Each model got the excerpt image and the prompt above, with no system prompt and no tools. All models ran at their high reasoning setting. Each excerpt was asked twice, in separate requests.

For grading, GPT-6 Luna read each model's full response next to the right bar number, without the image, and replied correct or incorrect:

A model was shown part of a score in which one note had been modified, and asked which measure the modified note is in.
